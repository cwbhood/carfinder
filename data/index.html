The dataset

Everything CarFinder shows comes from these JSON files: 5,700 new-vehicle price rows in 11 countries and the tax and fee rules applied to them, each US and Indian state rule with its citation. Free to use under the MIT licence and citable by DOI.

DOI 10.5281/zenodo.23382016Browse on GitHub

Price rows

One JSON array per vertical and country; each row is an array in the order documented in docs/DATA.md (make, model, body, size, price from base to top trim, efficiency, power, seats, drivetrain, the market heat that sets the dealer band, a note and whether the price is an estimate). 5,700 rows in 44 files.

Cite it

Every release is archived on Zenodo. To cite the dataset and app, use the concept DOI, which always resolves to the latest version: doi.org/10.5281/zenodo.23382016. Suggested citation: Jones, D. (2026). CarFinder 2026 [Data set and software]. Zenodo. https://doi.org/10.5281/zenodo.23382016. The repository’s CITATION.cff has the same in machine-readable form.

Licence: MIT, as for the whole repository. The prices and rules are compiled from the public sources named in each file; check a figure against its source before relying on it, and report anything wrong.
